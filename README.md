# Ml_Kamisha
Повторяю и продолжаю изучать ML

1. Изучить языковые модели (LLM)
   Как работают LLM, токены, контекстное окно, промпты, API, embeddings, temperature.
2. Попробовать разные типы нейросетей
   Текстовые, генерация изображений, видео, аудио, мультимодальные модели. Сравнить возможности.
3. Изучить готовые решения
   Ollama, Hugging Face, LangChain, LlamaIndex, готовые AI-агенты и сервисы.
4. Изучить OpenSpec
   Научиться описывать требования, планировать задачи и разрабатывать проекты с AI-ассистентами.
5. Изучить n8n
   Создавать автоматизации, подключать API, вызывать LLM и строить AI-workflow.
6. Изучить RAG-системы
   Embeddings, векторные базы данных, поиск по документам, построение собственного RAG.
7. Написать собственного AI-агента
   Python, LLM API, tool calling, память, выполнение действий и обработка ошибок.
8. Создать агента с подключением MCP
   Разобраться с MCP-клиентами и серверами, подключением внешних инструментов.
9. Изучить оркестрацию AI-агентов
   LangGraph, управление состояниями, маршрутизация задач, взаимодействие нескольких агентов.
10. Изучить дообучение нейросетей
   Fine-tuning, LoRA, QLoRA, подготовка датасетов, оценка качества моделей.
